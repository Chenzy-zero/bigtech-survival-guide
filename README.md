# 大厂生存指南 · BigTech Survival Guide

**名字叫《大厂生存指南》，但它并不打算教你如何正常地在大厂生存。**

一款手机优先的单页面荒诞职场选择游戏。玩家扮演刚毕业、进入一家虚构科技大厂的新人，从投简历一路经历面试、谈薪资、入职、花名、团建、试用期、紧急任务和复盘。

游戏世界的潜规则荒诞而反常识：你以为专业、负责、讲道理的选择能解决问题，下一步却可能因此背锅；溜须拍马、装忙、战略性摸鱼反而可能让你活得更久。目标不是成为模范员工，而是在这套扭曲的组织逻辑里尽可能生存下去。

## 本地运行

需要 Node.js 22 或兼容的现代 Node.js 版本。

```bash
npm install
npm run dev
```

运行测试和生产构建：

```bash
npm test
npm run build
npm run preview
```

## 当前原型

- 中文手机竖屏优先，打开页面即可开始。
- 每次展示一个职场事件与 2–4 个选择。
- 选择会推进剧情、留下标记、触发反转或结束游戏。
- 包含存活结局、被优化结局、过劳警示结局和荒诞晋升结局。
- 事件数据与游戏引擎分离，并在启动时校验重复 ID、无效跳转和不可达事件。
- 暂不包含账号、后端、数据库、复杂属性面板或运行时 AI 剧情生成。

## 设计原则

1. **反职场鸡汤**：这是黑色幽默与荒诞讽刺，不是严肃的职场教学指南。
2. **反常识但有线索**：看似正确的选择可能成为后续陷阱；反转要有铺垫，避免纯随机的作者杀。
3. **生存优先于道德积分**：组织可能奖励拍马屁、装忙和摸鱼，但这些策略也会在具体情境下翻车。
4. **简单优先**：轻量 Vite + TypeScript + 原生 CSS，不引入大型 UI 框架或后端。
5. **来源可追溯**：真实案例用于研究与启发，剧情使用虚构公司和复合情境，不把未经证实的传闻当事实。
6. **严肃对待现实伤害**：过劳等严重健康后果作为警示呈现，不当作轻佻笑料。
