# 大厂生存指南 · BigTech Survival Guide

一款手机优先的单页面文字选择游戏。玩家扮演刚毕业、进入大厂的新人，在招聘、入职、试用期、需求交付、团队关系和组织调整中连续做出选择，目标是在复杂的职场环境中生存下来。

> 当前阶段：项目初始化与设计归档。尚未开始实现游戏界面。

## 产品目标

- 手机竖屏优先，打开页面即可开始游戏。
- 每次呈现一个职场事件与 2–4 个行动选项。
- 选择会导致剧情推进、状态变化、陷阱触发或游戏结束。
- 失败后说明原因，支持重新开始。
- 以真实职场现象和可追溯资料为灵感，使用虚构公司与复合剧情进行讽刺性改编。

## 设计原则

1. **简单优先**：第一版不做账号、后端、多人玩法、复杂地图或 AI 实时生成剧情。
2. **选择有后果**：不把所有事件简化成单一正确答案；短期收益可能带来长期代价。
3. **可重玩**：不同选择能进入不同事件和结局。
4. **来源可追溯**：区分官方案例、媒体报道、个人自述和纯虚构内容。
5. **尊重玩家**：健康风险作为严肃后果处理，不把过劳或猝死仅当作笑料。
