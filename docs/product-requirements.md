# 产品需求与 MVP 范围

## 1. 产品定位

《大厂生存指南》是一款以中文互联网职场文化为背景的讽刺性文字选择游戏。玩家扮演刚毕业并进入一家虚构大型科技公司的新人，在连续的工作和人际情境中做出选择，目标是尽可能长期地生存，并找到适合自己的结局。

## 2. 目标用户与体验

- 想轻松体验职场黑色幽默的普通玩家。
- 即将进入职场或刚入职的毕业生。
- 对大厂文化、职场沟通和劳动权益感兴趣的人。

体验目标：打开页面即可理解怎么玩；每道题阅读时间短；选项有明显差异；失败能让人理解“为什么踩坑”；愿意重新开始尝试其他路径。

## 3. 核心用户流程

1. 打开游戏首页，看到标题、简短背景和开始按钮。
2. 进入第一道事件，看到章节/进度、事件标题、情境描述和 2–4 个选项。
3. 选择后显示简短反馈，或者直接进入下一事件。
4. 根据此前选择进入不同剧情；触发陷阱时进入游戏失败页。
5. 通关或失败后显示结局、关键选择回顾和重新开始按钮。

## 4. MVP 必须包含

- 单页面体验，优先适配手机竖屏。
- 首页、事件页、结果/结局页三个基本状态。
- 一次只展示一个事件。
- 每个事件通常有 2–4 个选择。
- 至少 12–20 个事件，覆盖求职、入职、试用期和首次紧急任务。
- 多条失败路径和至少一个存活结局。
- 失败说明与重新开始能力。
- 事件内容与页面逻辑分离，便于通过添加数据扩充剧情。
- 基础的事件数据校验，避免重复 ID、无效跳转和无法到达的结局。

## 5. 第一版暂不包含

- 用户注册、账号体系、云端存档和排行榜。
- 实时联网、多人玩法或玩家间社交。
- AI 在游戏过程中即时生成剧情。
- 复杂角色属性、装备、技能树、地图或战斗系统。
- 后台剧情编辑器、数据库和服务端 API。
- 复杂的音效、动画和商业化能力。

## 6. 成功标准

- 新玩家不看说明也能开始并完成一次游玩。
- 页面在常见手机宽度下没有横向溢出，选项可轻松触控。
- 所有事件 ID 唯一，所有跳转目标存在。
- 所有失败结局都有可理解的触发原因。
- 从开始到至少一个存活结局存在有效路径。
- 重新开始会清空本局状态，不残留上一局的选择。
- 研究资料能追溯到公开来源；虚构剧情不会被误称为真实个案。

## 7. 内容边界

游戏可以讽刺模糊需求、过度加班、职场黑话、绩效压力、团建边界和组织调整，但不要把违法行为描述成合理或必需的成功秘诀。劳动法律内容用于情境启发，不替代专业法律意见。
