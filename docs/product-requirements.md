# 产品需求与 MVP 范围

## 1. 产品定位

《大厂生存指南》是一款手机优先的荒诞职场文字选择游戏。玩家扮演刚毕业、进入一家虚构大型科技公司的新人，从求职开始，一路面对入职、试用期、工作交付、人际关系、绩效和组织调整。

“指南”是反讽。它不打算教玩家成为好员工，而是让玩家在荒谬的组织规则中求生：专业、负责、讲道理的做法经常在下一步变成自己的坑；溜须拍马、装忙、甩锅和摸鱼划水反而可能带来生存机会。游戏通过荒诞后果讽刺口头价值观与真实激励机制之间的冲突。

## 2. 目标体验

- 打开手机网页即可开始，无需注册或安装。
- 每道事件阅读简短，选择明确，一次只处理一个情境。
- 玩家会因反常识的后果感到意外，但回头能找到线索。
- 失败能揭示自己踩中的组织潜规则，并鼓励重新挑战。
- 生存不等于道德胜利；不同路径可以通往不同的荒诞结局。

## 3. 核心用户流程

1. 首页展示游戏标题、反讽式简介和开始按钮。
2. 游戏页展示章节/进度、事件标题、情境描述和 2–4 个选项。
3. 玩家选择后，展示简短反馈、反转或直接进入下一事件。
4. 之前的选择和剧情标记可能影响后续事件。
5. 触发陷阱后进入失败页，解释组织规则如何反噬玩家。
6. 通关或失败后显示结局、关键选择回顾和重新开始按钮。

## 4. MVP 必须包含

- 手机优先的单页面体验。
- 首页、事件页、结果/结局页三个基本状态。
- 一次只展示一个事件，每个事件通常有 2–4 个选项。
- 第一批约 12–20 个事件，覆盖求职、入职、试用期和首次紧急任务。
- 多条失败路径和至少一个存活结局。
- 失败原因说明与重新开始能力。
- 事件内容与页面逻辑分离。
- 基础事件校验，避免重复 ID、无效跳转和无法到达的结局。
- 至少有几个“看似正确、随后反噬”的反转，以及看似投机的选项意外奏效的情节。

## 5. 第一版暂不包含

- 用户注册、账号体系、云端存档和排行榜。
- 实时联网、多人玩法或玩家间社交。
- AI 在游戏过程中即时生成剧情。
- 复杂角色属性、装备、技能树、地图或战斗系统。
- 后台剧情编辑器、数据库和服务端 API。
- 复杂音效、动画和商业化能力。

## 6. 成功标准

- 新玩家不看说明也能开始并完成一次游玩。
- 页面适配常见手机宽度，选项可轻松触控。
- 所有事件 ID 唯一，所有跳转目标存在。
- 每个失败结局都有可理解的触发原因。
- 从开局到至少一个存活结局存在有效路径。
- 选择历史与剧情标记在重新开始时被清空。
- 反转既有意外性，也能从之前的线索或人物动机中找到解释。
- 研究资料可追溯，虚构剧情不会被误称为真实个案。

## 7. 内容边界

游戏可以讽刺过度加班、职场黑话、绩效压力、团建边界、向上管理和组织调整，但不把违法行为包装成现实中的成功秘诀。现实案例用于创作参考，游戏剧情不是法律、医疗或职场咨询。
