# 产品需求与 MVP 范围

## 1. 产品定位

《大厂生存指南》是一款手机优先的中文单页面荒诞职场选择游戏。玩家从应届生求职开始，经历简历、项目面试、薪资谈判、口头与书面 Offer、入职、团建、早会、紧急任务和线上事故。

“指南”是反讽。游戏不是在教人如何成为优秀员工，而是用荒诞后果讽刺职场里的空话、形式主义、隐性考核和责任错位。

## 2. 目标体验

- 打开手机网页即可开始，无需注册或安装。
- 每道题是一个简短、具体、生活化的场景。
- 不展示独立的“线索”卡片，不让玩家通过谜语或抽象提示猜作者心思。
- 玩家选择后立即看到反馈；选错可能当场失败，也可能继续进入下一场景。
- 求职到工作各阶段都拥有独立结局，不必玩到最后才统一结算。
- 失败说明具体发生了什么，并提供重新开始入口。
- 黑话来自可追溯的公开资料，区分历史梗、通用表达与个人经历。

## 3. 核心流程

1. 首页点击开始。
2. 展示一个场景、一个明确问题和 2–4 个具体选项。
3. 选择后立即显示后果；若目标是结局，直接显示对应结局页。
4. 继续路线进入下一场景。
5. 结局页展示失败/暂时存活的原因和选择回顾，并允许重新入职。

## 4. MVP 必须包含

- 手机优先的单页面体验。
- 求职阶段：简历、项目经历追问、项目数据、薪资沟通、口头 Offer、书面 Offer。
- 入职和工作阶段：花名/入职流程、团建、早会、紧急任务、线上事故和复盘。
- 多个按阶段命名的即时失败结局，以及至少一个暂时存活结局。
- 结局原因说明与重新开始能力。
- 事件内容与页面逻辑分离。
- 事件 ID、选项 ID、跳转目标、可达性和选项数量校验。
- 测试覆盖求职、Offer、入职、日常工作、紧急任务和复盘的失败路径。

## 5. 暂不包含

- 用户注册、账号体系、云端存档和排行榜。
- 后端、数据库、运行时 AI 生成剧情。
- 复杂角色属性、技能树、地图或战斗系统。
- 后台剧情编辑器、复杂音效、动画或商业化能力。

## 6. 成功标准

- 新玩家不看说明也能理解每道题并开始游玩。
- 大部分题干控制在 1–3 句，表达清楚人物、情境和直接问题。
- 选择错误时能进入对应阶段的独立结局，不会全部落到同一个通用结局。
- 简历、面试、薪资、口头 Offer、书面 Offer、入职/团建、日常汇报、紧急任务和事故处理均有可测试的失败路径。
- 页面适配常见手机宽度，选项可轻松触控。
- 所有事件 ID 唯一、跳转有效、节点可达，重新开始会清空本局状态。
- 研究资料可追溯，个体吐槽不会被写成某家公司的普遍事实。

## 7. 内容边界

本项目是虚构的职场荒诞讽刺游戏，不构成法律、医疗或职业咨询。真实案例仅用于研究和创作启发。过劳和健康风险严肃呈现，不作为奖励。
