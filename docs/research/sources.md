# 研究资料与案例来源

本文件归档项目讨论中收集的公开资料。来源用于理解现实问题和启发虚构剧情，不代表报道中的个别经历适用于所有企业。引用前应再次阅读原文并核对上下文。

## 证据等级说明

- A：政府部门、法院等官方公开材料。
- B：有明确作者/编辑和采访对象的媒体报道。
- C：游戏开发者访谈、设计复盘或官方游戏介绍，用于玩法参考。
- D：尚未核验的线索、个人帖子或二手转述；不应单独作为事实依据。

## 研究到剧情的转化规则

1. 每条来源使用唯一 ID，剧情事件引用 sourceIds。
2. 官方案例优先用于确认事件背景和法律争议；媒体采访用于理解个人感受和对话细节。
3. 多个案例可以合并为虚构的复合情境，但应在文档中标明“改编/综合”，不可伪装成逐字真实事件。
4. 不使用未经核验的匿名爆料作为指控特定公司的依据。
5. 定期检查链接是否仍可访问，并在使用前复核发布日期与上下文。
